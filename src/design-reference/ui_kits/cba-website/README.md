# Chase Bliss Website — UI Kit

Recreates [https://chasebliss.com](https://chasebliss.com) — the main marketing/ecommerce site built on Squarespace.

## Screens
1. **Home** — hero image + "Digital Brain Analog Heart" tagline strip + pedal SVG logos
2. **Pedals** — full product grid with thumbnails and taglines
3. **Product Page** — individual pedal (MOOD MKII) detail view
4. **About** — brand story excerpt

## Components
- `SiteNav` — top nav with logo, links, cart
- `HeroBanner` — full-bleed image hero
- `PedalGrid` — product listing cards
- `PedalCard` — individual product card (image, name, tagline)
- `ProductDetail` — single product layout
- `SiteFooter` — link columns + Digital Brain Analog Heart lockup

## Notes
- Site is Squarespace-hosted; font confirmed as **Poppins** (Google Fonts) — same as the firmware app.
- Product images are loaded from Squarespace CDN (public URLs).
- SVG assets (`Logomark`, `Digital Brain Analog Heart` tagline) are referenced from chasebliss.com/s/.
